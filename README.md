# Real-Time Chat Application

## Description

A real-time chat application built using Node.js, Express.js, and Socket.IO. Users can join the chat with a username, send messages instantly, and receive real-time updates when users join or leave the chat.

## Features

* Real-time messaging
* Username support
* Join and leave notifications
* Message timestamps
* Responsive user interface

## Technologies Used

* Node.js
* Express.js
* Socket.IO
* HTML
* CSS
* JavaScript

## How to Run

1. Clone the repository
2. Install dependencies

npm install

3. Start the server

node server.js

4. Open browser

http://localhost:3000
